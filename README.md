# Kiber-Şəbəkə Qoruyucusu (Cyber-Net Defender)

Python və Pygame əsasında hazırlanmış Obyekt Yönümlü Proqramlaşdırma (OOP) komanda layihəsi[cite: 1, 4].

## Oyun Haqqında
Oyunçu kiber-şəbəkəni xaotik hərəkət edən kiber-viruslardan, `+10 Coin` dronlarından və Boss dalğalarından qoruyur[cite: 3, 4, 7]. Oyunda mağaza (yeni gəmilər, EMP Bomba, Mini Dronlar, 20s Firewall Qalxanı), daimi xal/coin yaddaşı (`save_data.json`) və bonus rejim/mexaniklər mövcuddur[cite: 1, 8, 9].

## İdarəetmə Düymələri
- **Sol / Sağ / Yuxarı / Aşağı Oxlar:** Hərəkət (Klassik rejimdə sağ/sol, Sideways rejimdə yuxarı/aşağı)[cite: 1, 7, 12]
- **Space:** Atəş açmaq
- **Shift (Sol/Sağ):** Turbo sürət (2x)[cite: 1, 9, 12]
- **E:** 20 saniyəlik Firewall Qalxanını aktivləşdirmək[cite: 7, 9]
- **F:** EMP Bomba buraxmaq (uyğun gəmi və bomba alındıqda)[cite: 7, 9]
- **TAB:** Oyun rejimini dəyişmək (Klassik Şaquli / Sideways Shooter Üfüqi)[cite: 7, 9]
- **ESC:** Menyuya qayıtmaq[cite: 7]
- **Q** və ya **Pəncərənin X düyməsi:** Yadda saxlayıb çıxmaq[cite: 1, 7]
